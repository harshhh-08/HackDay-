# ADR-0005 — Minimal CLI for P0

- Date: 2026-10-25 local.
- Status: Accepted; CLI source is in `apps/cli/main.ts`. Its complete API-backed
  demonstration remains unverified pending service setup.

Choose a small TypeScript CLI as a real API client. It must submit, display actual
status/questions, send replies, show the full current plan/revision/hash/budget,
require explicit approval/rejection, cancel, and retrieve evidence/JSON/Markdown.
Business logic stays in API/application services. Escape untrusted terminal text.

A React/Vite dashboard is P1 once the complete flow works. No Stitch MCP tool is
available in this agent session, and P0 does not depend on design generation.
Use the same fixture and actual run artifacts; seeded demonstrations must be
clearly labeled. No fake progress percentages or duplicate UI-side state machine.
